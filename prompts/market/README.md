# Market & economic analysis prompts

These prompts read markets and the macro environment — synthesizing sentiment, classifying regimes, mining prediction markets, and consolidating feeds into structured views.

| Prompt | What it does |
|--------|--------------|
| [market-sentiment-tracker](market-sentiment-tracker.md) | Synthesize price, sentiment, and news into a market-narrative read |
| [macro-regime-monitor](macro-regime-monitor.md) | Classify the current macro regime from growth/inflation/liquidity indicators |
| [prediction-market-signal](prediction-market-signal.md) | Mine prediction markets for implied probabilities and flag divergences |
| [simulated-portfolio-manager](simulated-portfolio-manager.md) | A hypothetical portfolio-simulation exercise with risk rules and attribution |
| [intelligence-dashboard-aggregator](intelligence-dashboard-aggregator.md) | Consolidate multiple feeds into one structured dashboard view |

Every prompt is a standalone copy/paste tool — see the [prompt catalog](../README.md) for how the files are built and the [repository overview](../../README.md) for the full toolkit.

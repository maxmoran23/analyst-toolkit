# Reference data — NPA product risk

A small, committed sample of the synthetic input this framework's engine consumes.
It holds 700 proposals versus the 50,000 used for validation (1.4%). The full validation population is regenerated from seed into `data/`
(gitignored by design — credibility is reproduction-from-seed, not data-in-repo);
this pack exists so the framework folder is fully self-contained for a reader
browsing it on its own.

> **In plain terms:** One small spreadsheet of made-up new-product proposals, each built into a known
> risk band, so you can see what the product-risk engine reads before running the
> full 50,000-proposal validation.

## `products.csv` — 700 rows (validation scale: 50,000)

Fictional product / activity proposals (fictional Harborview Financial Group) with KNOWN designed-risk strata.

| Column | Meaning |
|---|---|
| `product_id` | Unique proposal identifier. |
| `stratum` | Ground truth: designed_low / designed_medium / designed_high / hard_high (one buried floor attribute) / prohibited. |
| `hard_type` | For hard_high / prohibited rows: which floor or prohibited attribute was planted. |
| `client_segment` | Target client segment. |
| `target_jurisdictions` | Target jurisdictions (pipe-separated risk buckets). |
| `delivery_channel` | Delivery channel. |
| `asset_settlement_type` | Asset / settlement type. |
| `novelty_to_firm` | Novelty grade of the product to the firm. |
| `third_party_dependency` | Third-party dependency grade. |
| `data_privacy_surface` | Data-privacy surface grade. |
| `cash_intensity` | Cash-intensity grade. |
| `anonymity_features` | Anonymity-features grade. |
| `cross_border_reach` | Cross-border-reach grade. |
| `model_ai_reliance` | Model / AI-reliance grade. |
| `involves_custody` | 1 if the proposal involves custody. |
| `sanctions_exposed_asset` | 1 if the underlying asset is sanctions-exposed (floor attribute). |
| `new_client_segment` | 1 if the segment is new to the firm. |
| `new_geography` | 1 if the geography is new to the firm (with new_client_segment: floor combination). |
| `anonymity_enhanced_instrument` | 1 if the instrument is anonymity-enhanced (prohibited attribute). |
| `bearer_negotiable_feature` | 1 if it carries a bearer-negotiable feature (prohibited attribute). |

## Regeneration

From the repository root:

```bash
python3 _tooling/build_reference_data.py --only npa-product-risk
```

The build is deterministic (seed 42): every run reproduces these files
byte-identically, and the `reference-data` CI job re-derives and diffs them on
every change, so this pack can never silently drift from the generator.

All records are seeded synthetic data produced by this framework's own
`generate_synthetic_data.py`. No real person, entity, account, or event is
represented; any resemblance to a real name is coincidental by construction.

**Confidence: HIGH — generated by the same seeded generator as the validation population and byte-verified by the `reference-data` CI job on every change.**

# Reference data — jurisdiction risk

A small, committed sample of the synthetic input this framework's engine consumes.
It holds 600 jurisdictions versus the 40,000 used for validation (1.5%). The full validation population is regenerated from seed into `data/`
(gitignored by design — credibility is reproduction-from-seed, not data-in-repo);
this pack exists so the framework folder is fully self-contained for a reader
browsing it on its own.

> **In plain terms:** One small spreadsheet of entirely fictional jurisdictions, each built into a known
> risk band, so you can see what the rating engine reads before running the full
> 40,000-jurisdiction validation. No real country appears anywhere in it.

## `jurisdictions.csv` — 600 rows (validation scale: 40,000)

FICTIONAL jurisdictions across five designed-risk strata; the stratum is assigned by construction, independently of the engine's formula.

| Column | Meaning |
|---|---|
| `code` | Invented jurisdiction code (J0001 ...) — deliberately not an ISO code. |
| `name` | Invented jurisdiction name. |
| `stratum` | Ground truth: designed_low / designed_medium / designed_high (soft dimensions only) or hard_high / hard_critical (moderate soft inputs plus one floor-triggering designation). |
| `cpi_score` | Corruption-perception style score (higher = cleaner). |
| `basel_score` | Basel-AML-index style score (higher = riskier). |
| `wgi_rule_of_law_pct` | Rule-of-law percentile (higher = better). |
| `wgi_control_corruption_pct` | Control-of-corruption percentile (higher = better). |
| `secrecy_score` | Financial-secrecy score (higher = riskier). |
| `organized_crime_score` | Organized-crime presence score (higher = riskier). |
| `terrorism_score` | Terrorism-exposure score (higher = riskier). |
| `instability_score` | Political-instability score (higher = riskier). |
| `comprehensive_sanctions` | 1 if under a comprehensive sanctions program (CRITICAL floor). |
| `fatf_blacklist` | 1 if on the FATF black list analogue (CRITICAL floor). |
| `fatf_greylist` | 1 if on the FATF grey list analogue (HIGH floor). |
| `eu_high_risk` | 1 if on the EU high-risk third-country analogue (HIGH floor). |
| `incsr_primary_concern` | 1 if an INCSR primary-concern analogue (HIGH floor). |
| `missing` | Pipe-separated context dimensions deliberately absent (exercises the engine's exclude-and-renormalize path). |

This framework's generator is an in-process library (it exposes
`make_jurisdictions()` rather than a CLI), so `build_reference_data.py` calls it
directly and writes the CSV in the generator's own field order.

## Regeneration

From the repository root:

```bash
python3 _tooling/build_reference_data.py --only jurisdiction-risk
```

The build is deterministic (seed 42): every run reproduces these files
byte-identically, and the `reference-data` CI job re-derives and diffs them on
every change, so this pack can never silently drift from the generator.

All records are seeded synthetic data produced by this framework's own
`generate_synthetic_data.py`. No real person, entity, account, or event is
represented; any resemblance to a real name is coincidental by construction.

**Confidence: HIGH — generated by the same seeded generator as the validation population and byte-verified by the `reference-data` CI job on every change.**

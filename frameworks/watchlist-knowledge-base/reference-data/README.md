# Reference data — watchlist knowledge base

A small, committed sample of the synthetic input this framework's engine consumes.
It holds records for 150 true entities versus the 3,000 used for validation (5%). The full validation population is regenerated from seed into `data/`
(gitignored by design — credibility is reproduction-from-seed, not data-in-repo);
this pack exists so the framework folder is fully self-contained for a reader
browsing it on its own.

> **In plain terms:** One small spreadsheet of made-up watchlist records as they would arrive from
> several public lists, with the true underlying entity attached, so you can see
> what the dedup engine reads before the full 3,000-entity validation.

## `list_records.csv` — 274 rows from 150 true entities (validation scale: 3,000 entities)

Records as delivered by several fictional public lists (OFAC / EU / UN / UK analogues). Cross-list duplicates share a strong identifier; confusable distractors share a surname token but never an identifier.

| Column | Meaning |
|---|---|
| `uid` | List-assigned record identifier. |
| `name` | Name as it appears on that list (varies across lists for the same entity). |
| `entity_type` | INDIVIDUAL / ENTITY / VESSEL / AIRCRAFT. |
| `program` | Invented program tag on that list. |
| `aliases` | Aliases on that list (pipe-separated). |
| `source` | Which fictional list delivered the record. |
| `true_entity_id` | Ground truth: the underlying real-world entity — records sharing it SHOULD be unified; records not sharing it must NEVER be merged. |
| `id_dob` | Date of birth as stated by that list (may be blank). |
| `id_nationality` | Nationality as stated (may be blank). |
| `id_country` | Country as stated (may be blank). |
| `id_place_of_birth` | Place of birth as stated (may be blank). |
| `id_passport` | Passport identifier (strong identifier; unique per true entity). |
| `id_national_id` | National identifier (strong identifier). |
| `id_registration` | Registration number (strong identifier, entities). |
| `id_imo` | IMO number (strong identifier, vessels). |
| `id_tail_number` | Tail number (strong identifier, aircraft). |
| `id_wallet` | Wallet identifier (strong identifier). |

## Regeneration

From the repository root:

```bash
python3 _tooling/build_reference_data.py --only watchlist-knowledge-base
```

The build is deterministic (seed 42): every run reproduces these files
byte-identically, and the `reference-data` CI job re-derives and diffs them on
every change, so this pack can never silently drift from the generator.

All records are seeded synthetic data produced by this framework's own
`generate_synthetic_data.py`. No real person, entity, account, or event is
represented; any resemblance to a real name is coincidental by construction.

**Confidence: HIGH — generated by the same seeded generator as the validation population and byte-verified by the `reference-data` CI job on every change.**

# Reference data — QA / independent-testing sampling

A small, committed sample of the synthetic input this framework's engine consumes.
It holds 12 controls with 250 items each versus 40,000 items per control at validation scale (0.6% — sized below the usual 1-5% to keep the pack under the ~150 KB cap). Note the sampling *conclusions* depend on population size, so this pack illustrates input shape, not the validated statistics. The full validation population is regenerated from seed into `data/`
(gitignored by design — credibility is reproduction-from-seed, not data-in-repo);
this pack exists so the framework folder is fully self-contained for a reader
browsing it on its own.

> **In plain terms:** Two small spreadsheets — a set of controls under test and the per-control item
> populations with known deviation labels — so you can see what the sampling engine
> reads before the full 40,000-items-per-control validation.

## `controls.csv` — 12 rows (validation scale: 12 controls)

Controls under test with stated plan parameters and a designed scenario.

| Column | Meaning |
|---|---|
| `control_id` | Unique control identifier. |
| `name` | Control name (fictional Harborview Financial Group). |
| `scenario` | Designed scenario: clean, boundary, failing, or planted (one wholly-deviant stratum). |
| `population` | Population size for this control in this pack (250 items each here; 40,000 at validation scale). |
| `confidence` | Stated confidence level for the attribute-sampling plan. |
| `tolerable_rate` | Tolerable deviation rate in the plan. |
| `expected_rate` | Expected deviation rate in the plan. |
| `true_rate` | Ground truth: the designed true deviation rate. |
| `planted_stratum` | For planted scenarios: the stratum that is 100% deviant. |

## `items.csv` — 3,000 rows (12 controls x 250 items; validation scale: 12 x 40,000)

Per-control population of test items.

| Column | Meaning |
|---|---|
| `control_id` | Control the item belongs to. |
| `item_id` | Item identifier within the control. |
| `stratum` | Stratum the item sits in (stratified selection operates over these). |
| `is_deviation` | Ground truth: 1 = genuine control deviation. |

## Regeneration

From the repository root:

```bash
python3 _tooling/build_reference_data.py --only qa-sampling
```

The build is deterministic (seed 42): every run reproduces these files
byte-identically, and the `reference-data` CI job re-derives and diffs them on
every change, so this pack can never silently drift from the generator.

All records are seeded synthetic data produced by this framework's own
`generate_synthetic_data.py`. No real person, entity, account, or event is
represented; any resemblance to a real name is coincidental by construction.

**Confidence: HIGH — generated by the same seeded generator as the validation population and byte-verified by the `reference-data` CI job on every change.**

# Output Templates

Reusable templates, design systems, and format guides for turning analytical work into
finished deliverables. Each subdirectory targets a different kind of output. Everything
here is generic and copy/paste-ready — bring your own content and data, and pair the
templates with an AI assistant to assemble the deliverable.

## Subdirectories

| Directory | What it provides |
|-----------|------------------|
| `dashboards/` | Design systems and templates for interactive HTML dashboards — multi-section analytical dashboards and lighter single-topic deep dives. |
| `pdf-reports/` | A design system for multi-page PDF reports — narrative, report-style document layouts. |
| `compliance-docs/` | AML/CFT compliance workbook specifications — control matrix, risk register, and independent testing workpaper. Generic, bank-grade, structured around FFIEC and FATF frameworks. |
| `communications/` | Templates for sharing work with people — an HTML email design system and a structured-update formatting guide for team channels. |
| `document-generation/` | Format primers for producing Word, PowerPoint, Excel, PDF, HTML, and visual-graphic deliverables with an AI assistant. |

## How to use

Open the README in any subdirectory for details and usage instructions. In general:

1. Pick the subdirectory matching the deliverable you need.
2. Read the relevant template or guide for its structure and conventions.
3. Hand it to an AI assistant along with your content — for example: *"Build this using
   the design system in this file."*
4. Review and iterate on the output.

The `document-generation/` guides are the lightweight starting point — format primers
with outlines and standards. The `dashboards/`, `pdf-reports/`, and `compliance-docs/`
directories go further, providing complete, opinionated design systems and detailed
specifications for specific high-value deliverables.

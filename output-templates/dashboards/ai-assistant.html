AI Analyst Component - self-demo

This file carries a generic, self-contained, in-dashboard AI analyst sidebar: a deterministic intent parser, query engine, and insight engine that answer questions about data already loaded in a dashboard. No network calls, no dependencies, works from file://. Click the round button at the bottom right to open the panel and ask about the sample records below.

How to extract the component

Copy everything between these two exact marker lines into the host dashboard, just before its closing </body> tag:

<!-- ===== BEGIN AI ANALYST COMPONENT v1.0 (self-contained: style + markup + script) ===== -->

<!-- ===== END AI ANALYST COMPONENT ===== -->

Then replace the demo window.AIA_CONFIG script block below with one describing the host dashboard's own data, and delete this self-demo host section. The component reads only window.AIA_CONFIG; nothing else in this file is required.

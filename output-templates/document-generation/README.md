# Document Generation Guides

Guides for producing finished deliverables — Word, PowerPoint, Excel, PDF, HTML
dashboards, and visual graphics — with an AI assistant.

Each guide is format-specific. It explains what the assistant can do, gives reusable
structures and outlines for common document types, and lists the quality standards and
design conventions to ask for. They are platform-neutral: most current AI assistants can
produce these formats, whether through a built-in document tool/skill or by writing the
file with a standard library. You describe the deliverable; the assistant chooses the
mechanism available to it.

## The guides

| File | Format | Covers |
|------|--------|--------|
| `word-documents.md` | `.docx` | Reports, memos, proposals, EDD reviews, risk assessments, control matrices, SOPs. Includes full section outlines for each document type and formatting conventions. |
| `presentations.md` | `.pptx` | Briefing decks, pitch decks, training materials, regulatory briefings. Includes slide-by-slide outlines and design principles (one idea per slide, the 6x6 rule). |
| `spreadsheets.md` | `.xlsx` | Financial models, data analysis, tracking sheets, control matrices, risk registers, reconciliations. Includes multi-sheet structures and formatting standards. |
| `pdf-tools.md` | `.pdf` | Reading, extracting, form-filling, merging, splitting, batch processing, and generating PDFs from other formats. |
| `html-dashboards.md` | `.html` | Single-file interactive dashboards — intelligence terminals, analytics dashboards, monitoring cockpits. Includes a reference dark-theme design system and a quality checklist. |
| `visual-design.md` | `.png` / `.pdf` | Infographics, process diagrams, social graphics, generative art. |

## How to use

1. Pick the guide for the format you need.
2. Use its outlines and standards to write a clear request — name the document type, the
   sections you want, and any formatting, branding, or quality requirements.
3. Ask an AI assistant to produce the deliverable. Provide your content and data.
4. Review the output and iterate.

For richer, opinionated formats — full interactive dashboards and multi-page PDF
reports — see the sibling `dashboards/` and `pdf-reports/` directories, which provide
complete design systems rather than format primers.
